# data_collection

[![Documentation Status](https://readthedocs.org/projects/dvrk-data-collection/badge/?version=latest)](https://dvrk-data-collection.readthedocs.io)
[![ROS 2 CI](https://github.com/jhu-dvrk/data_collection/actions/workflows/ros_ci.yml/badge.svg)](https://github.com/jhu-dvrk/data_collection/actions/workflows/ros_ci.yml)

A multi-stream video record application using C++, GStreamer, and GTKmm. It allows creating flexible video streams via JSON configuration, provides live previews, and supports synchronized recording with timestamps. ROS topics can also be recorded along the videos.

The latest documentation is available at [dvrk-data-collection.readthedocs.io](https://dvrk-data-collection.readthedocs.io).
